# Police du titre de l’espace de travail

Roboto variable, fichier original `Roboto[wdth,wght].ttf` du dépôt Google Fonts :
https://github.com/google/fonts/tree/main/ofl/roboto

Source de téléchargement : https://raw.githubusercontent.com/google/fonts/main/ofl/roboto/Roboto%5Bwdth%2Cwght%5D.ttf

Licence SIL Open Font License 1.1 jointe dans Roboto-LICENSE.txt. Fichier hébergé localement, aucun appel Google Fonts/CDN depuis le navigateur. Relevé le 27 octobre 2026 ; empreinte dans le manifeste de preuves workspace-validation.json.

La police originale du raster fourni n’est pas identifiée. Roboto et les réglages optiques du titre sont une approximation comparée au raster, sans prétendre que le fichier source employait cette police. Texte courant : Arial/Helvetica/sans-serif système.
