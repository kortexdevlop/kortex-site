# Kortex V1.0.0 — notes préparatoires, non publiée

Ce document prépare la livraison ; il ne correspond pas à un tag ni à une release de production existante. Le statut et les blocages sont dans [DEPLOY_V1_0_0](../reports/DEPLOY_V1_0_0.md).

Périmètre visé : Windows x64 et Chromium/WebView2, outils Core WASM signés exécutés localement, catalogue/API et Runtime à origines séparées. Les cinq outils V1 sont calculatrice, convertisseur de casse, dates UTC/Unix, hash et explorateur CSV. Le sixième outil Base64 reste un exemple d'extension testé séparément ; sa présence en staging ne modifie pas silencieusement la matrice des cinq outils de livraison.

Fonctions éprouvées localement/staging selon leurs rapports : bureau multi-instances, permissions par ressource, compte email/mot de passe, synchronisation facultative, assistant à propositions consenties et parcours locaux. Le fonctionnement hors connexion concerne les outils déjà chargés/installés sous politique de confiance valide, pas toutes les fonctions cloud.

Limites à régler ou accepter explicitement avant diffusion : Google non configuré, absence de service de vérification/récupération email, signature Windows de production absente, RC et restauration distante encore ouvertes, alertes continues non activées. Aucune prise en charge Linux/macOS/Firefox/WebKit, offre payante, GPU guest ou exécution cloud en arrière-plan annoncée.

Les vrais liens de téléchargement, hashes, provenance, signature Windows et versions de déploiement seront ajoutés après leur vérification, sans lien factice ni ancien artefact rebaptisé.
