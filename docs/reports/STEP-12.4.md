# Rapport 12.4 — Explorateur CSV : interface, actions et stockage

27/10/2026, Windows. Base d1450f0. Lot 12.3–12.5 autorisé ; validation humaine formelle non inventée.

Interface construite uniquement avec les composants génériques `tabs`, `table`, `select`, `input`, `svg-chart`, `progress`, `alert` : onglets Aperçu / Statistiques / Graphique, table paginée de 50 lignes, recherche par colonne, graphique en barres ou courbe (500 valeurs au plus), export du rapport via `file.save`, fichiers récents via `storage.read/write` sur clic explicite. Aucun widget propre au CSV, aucune modification de `kortex-ui` ni du contrat gelé. L’action `summarize_csv` utilise exactement le même analyseur que l’interface.

Tests Rust (tests/ui.rs, 5) : pagination, recherche, onglets, choix de colonne et de type de graphique, sortie d’action égale aux statistiques de l’interface ; fichiers hostiles sans table résiduelle ; refus, annulation et résultats tardifs ; export et stockage avec refus ; arbre valide pour 5 000×50. Test Web Chromium (Chrome système) avec le vrai sélecteur de fichier, le vrai paquet signé et les vraies permissions : refus avant lecture, 120 lignes, pagination, recherche, statistiques, 120 barres puis courbe, action identique, téléchargement `rapport-csv.csv` égal à l’action `export_report`, refus d’export, stockage fermé sans origine dédiée, aucun trafic réseau hors polices de l’hôte, fichier invalide. Tests Wasmtime Windows : fichier disque de plus de 800 Kio en trois blocs avec handles réels, 4 000 lignes, refus de `file.save`, écriture puis relecture de `prefs/recent` après redémarrage, refus du stockage. Interface WebView2 : action `summarize_csv` et refus de permission.

Limites : WebKit non exécuté (pas de navigateur Playwright installé) ; dialogue natif de sauvegarde/sélection Windows non automatisé ; stockage Web réel dépendant d’une origine d’exécution dédiée, attendu dans le test staging après publication. L’isolation du stockage entre outils reste couverte par crates/kortex-runtime-native/tests/capabilities.rs, web-adapter/tests/capabilities.spec.ts et crates/kortex-capabilities.
